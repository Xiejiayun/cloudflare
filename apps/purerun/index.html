隐私政策

最后更新：2026-07-29

政策概述

PureRun 是一款在本机运行的跑步记录器。PureRun 没有账号、广告、分析或第三方追踪 SDK，也不会把你的定位、运动或跑步记录上传到开发者服务器。

按照 App Store 隐私标签的定义，PureRun 选择「不收集数据（Data Not Collected）」。

本机处理的数据

经你授权后，PureRun 会在设备上处理以下数据以完成跑步记录：

  • 精确位置：测量距离并绘制跑步路线。
  • 运动与健身读数：GPS 较弱时提供距离兜底，必要时把步数换算为近似距离。
  • 跑步结果：距离、时长、平均配速、分段、卡路里估算和路线坐标。
  • App 设置：距离单位、外观、地图样式、语音提示、保持亮屏和引导完成状态。

路线与跑步结果使用 SwiftData 保存在 App 沙盒中，设置使用 UserDefaults 保存。原始步数不会保存。PureRun 不读取楼层、心率或 HealthKit 数据。

定位权限

  • PureRun 只请求「使用 App 期间」定位，不请求「始终」定位。
  • 跑步页显示时，前台定位用于判断 GPS 是否就绪。
  • 只有正在记录跑步时才启用后台定位，以便锁屏或切换 App 后继续记录。
  • 暂停或结束跑步后，后台定位立即关闭；暂停期间的移动不会计入距离或路线。
  • 定位点只保存在本机，不会上传或共享。

如果拒绝定位权限，PureRun 仍可打开，但无法正常记录室外距离和路线。

运动与健身权限

PureRun 只在跑步进行中使用 CMPedometer。它优先读取 iOS 给出的距离估算；如果该值不可用，可能读取步数并换算为近似距离。原始步数不会保存，也不会上传。

如果拒绝运动与健身权限，GPS 记录仍可工作，但室内或弱 GPS 环境下的距离可能不准确。

网络与第三方服务

PureRun 不包含第三方广告、分析、崩溃上报、社交或追踪 SDK，也不自行发起数据上传请求。

路线地图使用 Apple MapKit。MapKit 可能向 Apple 请求地图内容；这些请求由 Apple 的系统框架处理，并受 Apple 的隐私政策约束。

GPX 导出

你可以主动把单次跑步导出为 GPX 文件。文件通过 iOS 系统分享面板交给你选择的目标。导出后的处理取决于你选择的 App 或服务，请只分享给你信任的目的地。

删除与保留

你可以在训练日志中删除单次跑步。卸载 PureRun 会删除 App 沙盒中的跑步记录和设置。PureRun 未提供账号或云端同步，因此开发者没有服务器副本可供恢复或删除。

儿童隐私

PureRun 不是 Made for Kids App，不提供账号、广告、社交或用户生成内容，也不会把儿童或成人的数据发送给开发者。

政策变更

如果未来版本改变数据处理方式，PureRun 会在新功能上线前更新本政策、App 内说明和 App Store 隐私标签。

使用支持

  1. 在 iOS「设置 → 隐私与安全性 → 定位服务 → PureRun」中选择「使用 App 期间」。
  2. 室内或弱 GPS 跑步时，请在「运动与健身」中允许 PureRun。
  3. 先开始跑步再锁屏；暂停会停止后台定位，暂停期间的移动不会计入跑步。
  4. 导出 GPX 时，在系统分享面板中选择「存储到文件」或你信任的目标。

联系支持时，请提供 iPhone 型号、iOS 版本、PureRun 版本和问题发生步骤。除非确有必要并且你愿意分享，请不要发送包含家庭地址或敏感路线的截图或 GPX。

Privacy Policy

Last updated: July 29, 2026

Overview

PureRun is an on-device running tracker. It has no account, advertising, analytics, or third-party tracking SDKs, and it does not upload location, motion, or run records to a developer server.

Under the App Store privacy-label definition, PureRun selects Data Not Collected.

Data processed on the device

With your permission, PureRun processes:

  • Precise location to measure distance and draw a route.
  • Motion and fitness readings as a distance fallback when GPS is weak, including an approximate conversion from steps when needed.
  • Run results including distance, duration, average pace, splits, estimated calories, and route coordinates.
  • Preferences including unit, appearance, map style, spoken cues, screen behavior, and onboarding state.

Routes and run results are stored in the app sandbox with SwiftData. Preferences are stored with UserDefaults. Raw step counts are not stored. PureRun does not read floors, heart rate, or HealthKit data.

Location permission

  • PureRun requests When-In-Use authorization only, never Always.
  • Foreground location on the Run screen establishes GPS readiness.
  • Background location is enabled only while a run is actively recording so tracking can continue with the screen locked or another app open.
  • Pausing or ending a run disables background location. Paused movement is not added to distance or route.
  • Location points stay on the device and are not uploaded or shared.

If permission is denied, PureRun can still open but cannot reliably record outdoor distance and route.

Motion & Fitness permission

PureRun uses CMPedometer only during an active run. It prefers the distance estimate supplied by iOS; if unavailable, it may read steps and convert them into approximate distance. Raw step counts are not stored or uploaded.

If permission is denied, GPS tracking still works, but indoor or weak-GPS distance may be less accurate.

Network and third-party services

PureRun contains no third-party advertising, analytics, crash-reporting, social, or tracking SDKs and makes no data-upload requests of its own.

Route maps use Apple MapKit. MapKit may request map content from Apple through the system framework; those requests are governed by Apple's privacy policy.

GPX export

You may choose to export one run as a GPX file through the iOS share sheet. The selected destination controls the file after export. Share only with destinations you trust.

Retention and deletion

You can delete an individual run from the Training Log. Uninstalling PureRun removes runs and settings from the app sandbox. Because PureRun has no account or cloud sync, the developer has no server copy to recover or delete.

Children's privacy

PureRun is not a Made for Kids app. It has no account, advertising, social features, or user-generated content and does not transmit a child's or adult's data to the developer.

Policy changes

If a future release changes data handling, PureRun will update this policy, the in-app explanation, and the App Store privacy label before the feature ships.

Support

  1. In iOS Settings, confirm Privacy & Security → Location Services → PureRun is set to While Using the App.
  2. Allow Motion & Fitness for PureRun when using indoor or weak-GPS distance fallback.
  3. Start the run before locking the screen. Pausing disables background location and excludes paused movement.
  4. For GPX export, choose Save to Files or another trusted destination in the system share sheet.

When contacting support, include the iPhone model, iOS version, PureRun version, and reproduction steps. Avoid sending a screenshot or GPX containing a home address or sensitive route unless necessary and you are comfortable sharing it.
